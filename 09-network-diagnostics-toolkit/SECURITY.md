# Security Policy — IT Support Ticketing System

## Supported Versions

| Version | Supported |
|---------|-----------|
| 1.x     | Yes       |

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it responsibly.

**Do NOT open a public GitHub issue for security vulnerabilities.**

Instead, email: security@rivi-enterprises.com

**Include in your report:**
- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested fix (if any)

We will respond within 48 hours and work to resolve the issue promptly.

## Security Notes for Lab Use

- This tool is designed for lab and educational environments only
- Do not store real employee data or credentials in tickets_db.json
- The audit.log file may contain sensitive ticket information — protect it accordingly
- This tool has no authentication by default — add auth before any production use

## Ethical Use

This project is governed by the IT Act 2000 (India) and CFAA (USA).
Use only in authorized lab environments on systems you own or have explicit permission to test.
