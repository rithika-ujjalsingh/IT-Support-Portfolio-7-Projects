| # | Filename | What to capture | VM to use |
|---|---|---|---|
| 1 | `01-task-manager-sorted-by-cpu.png` | Task Manager Processes tab, sorted by CPU descending | Windows 11 |
| 2 | `02-event-viewer-application-errors.png` | Event Viewer with Application log filtered to Error level | Windows 11 |

| 6 | `06-systeminfo-output.png` | CMD output of the systeminfo filtered command | Windows 11 |

## Tips

- For Task Manager, click "More details" first if it opens in compact mode
- For Event Viewer, if there are no real errors, generate one by force-closing an app from Task Manager first
- For Safe Mode, you only need ONE screenshot of the desktop — no need to repeat every step
