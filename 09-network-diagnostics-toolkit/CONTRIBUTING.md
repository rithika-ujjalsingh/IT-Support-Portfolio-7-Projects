# Contributing to IT Support Ticketing System

Thank you for your interest in contributing!

## How to Contribute

### Step 1: Fork the Repository
Click the Fork button on the GitHub repository page.

### Step 2: Clone Your Fork
```bash
git clone https://github.com/YOUR-USERNAME/IT-Support-Ticketing-System.git
cd IT-Support-Ticketing-System
```

### Step 3: Create a New Branch
```bash
git checkout -b feature/your-feature-name
# Example: git checkout -b feature/add-email-notifications
```

### Step 4: Make Your Changes
- Follow the existing code style
- Add comments explaining what your code does
- Test your changes locally before submitting

### Step 5: Commit Your Changes
```bash
git add .
git commit -m "Add: brief description of your change"
# Use these prefixes:
# Add:    new feature
# Fix:    bug fix
# Update: improvement to existing feature
# Docs:   documentation only change
```

### Step 6: Push and Create Pull Request
```bash
git push origin feature/your-feature-name
```
Then go to GitHub and click "New Pull Request".

## Code Style Guidelines
- Use clear variable names
- Add docstrings to all functions
- Keep functions small and focused
- Add error handling for user inputs

## Ideas for Contributions
- Email notifications for escalations
- Web-based GUI using Flask
- Integration with real Active Directory
- More detailed SLA reports
- Multi-user authentication
